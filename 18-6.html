三、核心实现：Mermaid 使用要点

Mermaid 库已按要求下载到本地 cdn/mermaid/ 目录（mermaid.min.js 约 3.5MB，官方发行版 UMD 构建），页面以相对路径引用、离线可用。用法：先 mermaid.initialize() 配置主题，再调用 mermaid.render(唯一id, 图表语法) 得到 SVG 字符串插入容器；图表本身只需书写 mermaid 文本语法（flowchart / erDiagram），无需手写图形坐标。

// 1. 初始化（关闭自动渲染，改为手动控制）
mermaid.initialize({ startOnLoad: false, theme: 'default' });

// 2. 流程图语法（节选）
flowchart TD
    A["用户发起咨询"] --> B{"意图识别"}
    B -->|"业务咨询"| F["检索知识库"]
    F --> I["混合检索：向量+关键词+图谱"]
    I --> K["大模型 RAG 生成"]
    K --> M["答案返回用户"]
    M -.->|"反馈数据"| R["知识库更新与模型微调"]

// 3. ER 图语法（节选）
erDiagram
    USER ||--o{ SESSION : "发起"
    SESSION ||--o{ MESSAGE : "包含"
    KNOWLEDGE_BASE ||--o{ KNOWLEDGE_ITEM : "收录"
    USER {
        string user_id PK
        string nickname
    }

// 4. 渲染为 SVG 并插入页面
var yl_res = await mermaid.render('yl_svg_' + yl_n, yl_flowCode);
document.getElementById('yl_flowBox').innerHTML = yl_res.svg;
