CSS 长度单位展示

绝对单位（px / pt / cm / in）与相对单位（% / em / rem / vw / vh / vmin / vmax / ch / ex）可视化对比

px 像素

绝对单位，不随屏幕或字体变化

100px

pt / cm / in

印刷单位：1in = 96px，1cm ≈ 37.8px，1pt ≈ 1.33px

72pt×48pt
2cm
1in×0.6in

% 百分比

相对父元素尺寸，虚线框为父容器（260×150）

width:75%
height:70%

em

相对父元素 font-size，逐层相乘（内层 1.6em 比外层大）

font-size:1em
font-size:1.6em（叠加变大）

rem

永远相对根 html（16px），不受父层 font-size 影响

font-size:1rem
font-size:1.6rem（基准一致）

vw 视口宽度

1vw = 视口宽 1%，三条彩带随窗口实时伸缩

width: 25vw
width: 50vw
width: 75vw

vh 视口高度

1vh = 视口高 1%，拖动窗口高度试试

15vh
25vh

vmin / vmax

vmin 取视口宽高中较小者，vmax 取较大者

20vmin
12vmax

ch 字符宽度

1ch ≈ 一个数字 "0" 的宽度，适合控制每行字数

width: 20ch 的容器，每行大约能放 20 个数字字符。

ex 字符高度

1ex ≈ 小写 "x" 的高度（字形 x-height）
