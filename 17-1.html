JSON 数据展示

JavaScript Object Notation —— 轻量级数据交换格式：语法、六种数据类型、JSON.parse() 与 JSON.stringify()

一、JSON 是什么

JSON（JavaScript Object Notation，JS 对象表示法）是一种轻量级的数据交换格式。它采用完全独立于编程语言的文本格式来存储和表示数据，易于人阅读和编写，也易于机器解析和生成，是目前前后端交互中最主流的数据格式。

  • 数据保存在名称/值对（键值对）中，键必须用双引号包裹："name": "张浩扬"
  • 多条数据之间用逗号分隔，最后一项后面不能有逗号。
  • 花括号 {} 保存对象，方括号 [] 保存数组。
  • 字符串只能用双引号（不能用单引号）；JSON 中没有注释、undefined、函数和日期类型。

二、六种数据类型

类型 示例 说明
字符串 string "hello" 双引号包裹，支持 \n \t \" 等转义字符
数字 number 42、3.14 整数或浮点数，没有 NaN 和 Infinity
布尔 boolean true、false 只有小写的 true / false
空 null null 表示"没有值"，注意不是 undefined
对象 object { "k": "v" } 键值对的无序集合，键必须加双引号
数组 array [1, 2, 3] 值的有序集合，元素类型可以不同

五、小结

  • JSON.parse(text)：把 JSON 字符串转换成 JavaScript 对象 / 数组；文本不合法时会抛出异常，实际开发中要用 try...catch 捕获。
  • JSON.stringify(value)：把 JavaScript 对象 / 数组转换成 JSON 字符串；第二个参数可传筛选数组，第三个参数可传缩进空格数（如 JSON.stringify(obj, null, 2)）。
  • 常见书写错误：使用单引号、键没加引号、末尾多写逗号、字符串里有未转义的换行、把 undefined / 函数当作值。
  • JSON 与 JavaScript 对象字面量的区别：JSON 是文本格式，键必须双引号、不能有注释、没有 undefined。
