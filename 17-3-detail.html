核心实现：fetch + 原生代码

详情页先用原生 URLSearchParams 从地址栏读取商品 id（如 17-3-detail.html?id=3），再用 fetch() 按 id 请求单个商品接口，最后用原生 DOM 操作渲染图集、价格、参数与评论。考虑到接口网络波动，实际代码在 fetch 外层封装了自动重试（失败后延时 2 秒重试，最多 3 次）。核心代码如下：

// 1. 从地址栏读取商品 id：17-3-detail.html?id=3
var yl_id = Number(new URLSearchParams(location.search).get('id')) || 1;

// 2. fetch 按 id 获取单个商品
fetch('https://dummyjson.com/products/' + yl_id)
    .then(function (yl_resp) {
        if (!yl_resp.ok) {
            throw new Error('HTTP ' + yl_resp.status);
        }
        return yl_resp.json(); // 把响应体解析成 JSON 对象
    })
    .then(function (yl_data) {
        yl_renderDetail(yl_data); // 原生 DOM 渲染商品详情
    })
    .catch(function (yl_err) {
        yl_setStatus('err', '获取失败：' + yl_err.message);
    });
