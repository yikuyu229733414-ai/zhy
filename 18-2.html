二、核心实现：Canvas 绘图要点

用 canvas.getContext('2d') 获取绘图上下文，把七层结构写成数据数组，循环绘制圆角矩形（arcTo）、文字（fillText）与箭头（moveTo/lineTo）；鼠标坐标经缩放换算后做命中检测，实现悬停高亮与说明展示。

// 2. 圆角矩形模块
function yl_roundRect(yl_ctx, yl_x, yl_y, yl_w, yl_h, yl_r) {
    yl_ctx.moveTo(yl_x + yl_r, yl_y);
    yl_ctx.arcTo(yl_x + yl_w, yl_y, yl_x + yl_w, yl_y + yl_h, yl_r);
    yl_ctx.arcTo(yl_x + yl_w, yl_y + yl_h, yl_x, yl_y + yl_h, yl_r);
    yl_ctx.arcTo(yl_x, yl_y + yl_h, yl_x, yl_y, yl_r);
    yl_ctx.arcTo(yl_x, yl_y, yl_x + yl_w, yl_y, yl_r);
}
