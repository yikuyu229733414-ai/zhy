远程接口测试工具

使用 fetch 和原生代码实现（无第三方库 / CDN）：支持 GET / POST / PUT / PATCH / DELETE 请求调试，可编辑请求地址、请求头与请求体，实时展示状态码、耗时、响应大小、返回数据与错误提示信息。

一、请求设置

提示：GET / HEAD 请求不发送请求体；实例接口为 jsonplaceholder 测试接口（POST 提交后返回模拟创建结果）。

三、核心实现：fetch + 原生代码

用 fetch(url, options) 发送请求：方法、请求头、请求体都放在第二个参数的选项对象里；用 yl_resp.ok 判断状态码是否为 2xx，用 yl_resp.text() 读取原始返回再尝试解析 JSON；网络异常由 .catch 捕获并展示错误提示信息。核心代码如下：

// 1. 组装 fetch 选项：方法、请求头、请求体
var yl_options = {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ title: '标题', body: '内容', userId: 1 })
};

// 2. fetch 发送请求，读取原始文本后解析
fetch('https://jsonplaceholder.typicode.com/posts', yl_options)
    .then(function (yl_resp) {
        return yl_resp.text().then(function (yl_text) {
            return { yl_ok: yl_resp.ok, yl_status: yl_resp.status, yl_text: yl_text };
        });
    })
    .then(function (yl_pack) {
        yl_render(yl_pack); // 展示状态码、耗时与返回数据
    })
    .catch(function (yl_err) {
        yl_showError('网络错误：' + yl_err.message); // 错误提示信息
    });
