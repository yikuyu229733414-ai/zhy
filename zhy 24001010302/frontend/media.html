语音与图片识别

语音识别使用 Qwen ASR（Qwen/Qwen3-ASR-1.7B），图片识别使用 DeepSeek V4.1-Flash 视觉模型。前端上传文件 → Express 中间层转发硅基流动接口 → 返回识别结果（JSON）。API Key 只保存在后端 backend/.env，请求与响应均输出到浏览器控制台与后端终端。

1. 语音识别（Qwen ASR）

支持 wav / mp3 / m4a / flac / ogg / webm 等音频格式，单个文件不超过 20MB。

识别文本

（尚未识别）
返回 JSON 数据结构约定 
{
  "code": 0,
  "msg": "识别成功",
  "data": {
    "yuan_filename": "xxx.wav",
    "yuan_text": "识别出的文本",
    "yuan_model": "Qwen/Qwen3-ASR-1.7B",
    "yuan_response": { "text": "识别出的文本", "usage": { "type": "duration", "seconds": 4 } }
  }
