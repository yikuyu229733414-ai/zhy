Canvas 动画 · 我的名字

HTML5 Canvas 绘制的动画效果，画面中的文字是"张浩扬"——粒子汇聚文字与波浪渐变文字两种特效（原生 JS，requestAnimationFrame 驱动）。

一、动画演示（可点击按钮切换效果）

提示：粒子文字模式下，把鼠标移到文字上会把粒子推开，松开后自动归位；"炸散重组"让粒子四散后重新汇聚成"张浩扬"。

二、核心实现：Canvas 绘制要点

canvas.getContext('2d') 获取绘图上下文；粒子文字先用离屏画布把文字"张浩扬"画出来，再用 getImageData() 按像素采样得到每个粒子的目标坐标，最后用 requestAnimationFrame() 循环重绘；波浪文字用 fillText() 逐字绘制并按正弦函数偏移纵坐标。

// 1. 离屏采样：把文字画到隐藏画布，读取像素得到粒子目标点
yl_octx.font = 'bold 130px "Microsoft YaHei"';
yl_octx.fillText('张浩扬', yl_w / 2, yl_h / 2);
var yl_pixels = yl_octx.getImageData(0, 0, yl_w, yl_h).data;
// 透明度大于 128 的像素点，每隔 5px 取一个作为粒子目标

// 2. 每帧动画：粒子向目标点缓动 + 轻微抖动
yl_particles.forEach(function (yl_p) {
    yl_p.x += (yl_p.tx - yl_p.x) * 0.08;   // 缓动靠拢
    yl_p.y += (yl_p.ty - yl_p.y) * 0.08;
    yl_ctx.fillRect(yl_p.x, yl_p.y, yl_p.size, yl_p.size);
});
