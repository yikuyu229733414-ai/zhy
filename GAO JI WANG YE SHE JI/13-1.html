Font Awesome 字体图标展示

字体图标 = 一个图标字体文件 + 一段 CSS 映射：每个图标对应字体里的一个字符编码（如 &#xf015;）， 浏览器把它当"文字"渲染，因此可以用 font-size、color 像控制文字一样控制图标。本页资源已本地化到 cdn/fontawesome/。

与文字 / 按钮混排

图标与文字同行排列，继承同一字体上下文

提示：字体图标可像文字一样参与行内排版
字体图标原理：CSS 的 @font-face 加载本地字体文件 webfonts/fa-solid-900.woff2， .fa-house::before { content: "\f015" } 把图标映射为一个字符。
优点：体积小、可用 font-size/color 控制、兼容性好；缺点：单色、无法改内部细节。资源位于 cdn/fontawesome/。
