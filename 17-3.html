商品列表（DummyJSON 接口）

使用 fetch 和原生代码实现（无第三方库 / CDN）：调用商品接口获取默认商品列表，点击商品卡片进入详情页查看单个商品。

列表接口：https://dummyjson.com/products?limit=8（详情接口：https://dummyjson.com/products/{id}）

准备就绪：点击"重新获取"拉取商品列表（需要联网）。

核心实现：fetch + 原生代码

列表页用 fetch() 请求商品列表接口，拿到 JSON 后用原生 DOM 操作（createElement / textContent / appendChild）渲染商品卡片；每张卡片是超链接，携带商品 id 跳转到 17-3-detail.html。考虑到接口网络波动，实际代码在 fetch 外层封装了自动重试（失败后延时 2 秒重试，最多 3 次）。核心代码如下：

// 1. 列表接口：默认取 8 个商品
var yl_url = 'https://dummyjson.com/products?limit=8';

// 2. fetch 发起请求，返回 Promise
fetch(yl_url)
    .then(function (yl_resp) {
        if (!yl_resp.ok) {
            throw new Error('HTTP ' + yl_resp.status);
        }
        return yl_resp.json(); // 把响应体解析成 JSON 对象
    })
    .then(function (yl_data) {
        yl_renderList(yl_data.products); // 原生 DOM 渲染商品卡片
    })
    .catch(function (yl_err) {
        yl_setStatus('err', '获取失败：' + yl_err.message);
    });

// 3. 卡片链接携带 id 跳转详情页
//    <a href="17-3-detail.html?id=1">...</a>
